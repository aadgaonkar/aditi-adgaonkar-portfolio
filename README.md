# NYC Café Dilemma - Final Project Part I

This folder contains a GitHub Pages-ready Part I proposal, fully labeled conceptual sketches, and links to primary datasets.

## Publish
1. Add the entire `nyc-cafe-final-project` folder to the root of your existing GitHub Pages repository.
2. Add a link from your portfolio landing page to `nyc-cafe-final-project/` (or `nyc-cafe-final-project/index.html`).
3. Test the live `github.io` address, including each image and data link.
4. Submit the live **page URL**, not a GitHub source URL, to Canvas.

The `.md` source is also included as required by the assignment. All numbers in visual wireframes are placeholders and are identified as such.
